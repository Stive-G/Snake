# Snake

Projet de jeu Snake realise avec Unity 2022.3.5f1.

## Lancer le projet

1. Cloner ce depot.
2. Dans Unity Hub, ajouter le dossier du depot comme projet.
3. Ouvrir le projet avec Unity 2022.3.5f1 et attendre la fin de l'import.
4. Dans Assets/Scenes, ouvrir MenuScene.unity par un double-clic.
5. Cliquer sur Play, puis lancer une nouvelle partie depuis le menu.

Si Unity affiche une scene vide nommee Untitled, ouvrir MenuScene.unity.

## Commandes

- W : haut
- S : bas
- A : gauche
- D : droite
- P : afficher le menu de pause

## Contenu

- Assets : scenes, scripts, prefabs, sprites et sons.
- Packages : dependances Unity.
- ProjectSettings : configuration du projet.

Les dossiers temporaires Unity sont exclus de Git et regeneres a l'ouverture du projet.
